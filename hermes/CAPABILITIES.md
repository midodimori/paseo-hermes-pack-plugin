# Package capabilities

These are package features and setup options. Installation does not grant account access or activate every optional tool.

| Feature | Included behavior |
|---|---|
| Character | Generic SOUL; assistant name supplied during setup |
| Contextual review | `review-context` recommends one useful action, deferral, or silence from authorized context |
| Native memory | `maintain-memory` saves, corrects, and forgets durable facts through Hermes's memory tool |
| Personal diary | `diary-note`, `diary-search`, and `diary-forget` maintain detailed dated history in the profile |
| Pack improvement | `maintain-pack` prepares portable source improvements; publication and application require owner authorization |
| Conversations | Native ACP provider, readable streamed replies, and profile-local context |
| Model settings | Native model selection and conversation-specific thinking controls |
| Commands | Native management commands, profile-local cron controls, and installed skill shortcuts |
| Scheduled review | Optional hourly native cron seed with continuity, medium thinking, and local failure records |
| Findings | Dedicated Paseo conversation; direct assistant messages and completion notifications without extra inference |
| Starting preferences | Optional private facts seeded only into empty native user memory |
| Delegation | Optional installation of Paseo's upstream reference skill for its CLI, agents, and workspaces |
| Lifecycle | Guided install/update/uninstall, native distribution ownership, preserved runtime data, and one latest backup |

## Optional setup

| Option | Setup |
|---|---|
| Hermes bundled skills | Native opt-in and skill selection |
| Search | DDGS backend through native tool setup |
| Extraction | Native Exa free-tier configuration |
| Browser | Local native browser backend and executable setup |
| Vision | Main model provider, subject to model support |
| Proton | Community CLI, guarded upstream skill, private sign-in, and an optional read-only Mail/Calendar policy |
| Other apps | Native MCP and plugin setup catalogs |
| External memory | Native memory-provider setup |

Native capability availability depends on the installed Hermes version, platform, backends, and account permissions. Inspect effective tools and skills in the profile before relying on an optional feature.
