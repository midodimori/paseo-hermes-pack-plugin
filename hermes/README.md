# Native Hermes profile

This directory contains the assistant's native distribution: SOUL, configuration, six skills, setup seeds, optional Proton policy, and the Paseo delivery plugin.

Use the repository root's [installation guide](../README.md) and `./setup install`, `./setup update`, or `./setup uninstall`. The `hermes-pack` launcher in this directory provides the same commands.

Native profile files live under `~/.hermes/profiles/PROFILE`. The distribution owns only individual shipped files and extension directories. Personal memory, diary, sessions, credentials, schedules, learned skills, and independent extensions remain private.
